# QuantLab 部署说明

## 当前部署结构

- 前端：Cloudflare Pages，访问域名 `https://quantlab.aihzcc.top`。
- 后端：Render Web Service，建议域名 `https://api.quantlab.aihzcc.top`。
- GitHub：`https://github.com/hhzz-svg/QuantLab` 作为前后端部署源。

## Render 后端配置

在 Render Dashboard 新建 Web Service，选择 GitHub 仓库 `hhzz-svg/QuantLab`。

| 配置项 | 值 |
| --- | --- |
| Name | `quantlab-api` |
| Branch | `main` |
| Runtime | `Python` |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `uvicorn backend.main:app --host 0.0.0.0 --port $PORT` |
| Health Check Path | `/api/strategies` |

环境变量：

| Key | Value |
| --- | --- |
| `PYTHON_VERSION` | `3.12.10` |
| `DATABASE_URL` | `sqlite:////opt/render/project/src/data/quantlab.db` |

如果后续改用托管数据库，只需要把 `DATABASE_URL` 改成新的 SQLAlchemy 连接串，并补充对应数据库驱动依赖。

## 后端域名

Render 服务创建完成后，在 Render 的 Custom Domains 中添加：

```text
api.quantlab.aihzcc.top
```

然后在 Cloudflare DNS 中添加 Render 提示的 CNAME 记录。记录生效后，用下面地址验证后端：

```text
https://api.quantlab.aihzcc.top/api/strategies
```

## Cloudflare Pages 前端配置

在 Cloudflare Pages 项目 `quantlab` 中设置生产环境变量：

```text
VITE_API_BASE_URL=https://api.quantlab.aihzcc.top
```

保存后重新部署前端。前端会优先请求该后端地址；如果后端不可用，仍保留静态演示兜底逻辑，避免公网首页直接失效。
