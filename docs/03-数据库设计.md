# 03 数据库设计

| 表 | 作用 |
| --- | --- |
| symbols | 标的信息 |
| price_bars | 日线 OHLCV 行情 |
| backtest_runs | 回测任务配置 |
| backtest_metrics | 回测指标结果 |
| equity_points | 每日权益、现金、持仓、回撤、基准 |
| orders | 订单记录 |
| trades | 完整交易记录 |
| optimization_runs | 参数优化任务 |
| optimization_items | 参数候选结果 |

核心约束：`price_bars` 以 `symbol + source + date` 去重，避免重复同步导致行情污染。
