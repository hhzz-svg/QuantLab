# 06 毕业论文素材

## 可写章节

1. 绪论：量化投资系统研究背景与教学价值。
2. 需求分析：数据管理、策略配置、回测分析、参数优化和报告导出。
3. 系统设计：FastAPI + SQLite + Vue3 + ECharts 架构。
4. 核心算法：事件驱动回测、风险收益指标、参数网格搜索。
5. 系统实现：数据中心、策略中心、回测引擎、前端可视化。
6. 测试与结果分析：单元测试、API 测试、示例策略回测结果。
7. 总结与展望：接入更多数据源、扩展多资产组合和机器学习模型。

## 创新点表达

- 将成熟开源量化框架的分层思想简化为本科可实现版本。
- 同时提供策略研究、参数优化、历史任务、图表和报告闭环。
- 用 SQLite 保存可复现实验，便于论文展示和答辩演示。
