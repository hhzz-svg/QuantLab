# 01 需求文档

## 项目定位

QuantLab 面向企业内部投研、策略验证、项目评审和量化实验管理场景，提供一套可公网访问、可复盘、可演示的智能量化回测平台。平台通过 Cloudflare Pages 前端和 Render 后端 API 组成线上交付环境，帮助用户把临时策略验证沉淀为结构化研究流程和可追踪研究结果。

## 用户角色

- 策略研究者：配置策略、运行回测、比较参数并沉淀研究报告。
- 投资复盘用户：查看历史表现、权益曲线、回撤、交易记录和风险收益指标。
- 项目评审人员：通过线上地址查看产品能力、架构落地和研究闭环。

## 核心功能

1. 数据管理：同步 CSV/AKShare/yfinance 行情，统一入 SQLite。
2. 策略中心：展示 6 类策略的逻辑、参数、适用场景和风险提示。
3. 回测任务：配置标的、区间、资金、成本和策略参数。
4. 结果分析：展示收益、风险、交易、买入持有基准和图表。
5. 参数优化：对参数网格批量回测并排序。
6. 报告中心：导出 Markdown/HTML 策略报告。
7. 线上交付：前端公网入口连接 Render 后端 API，支持项目展示和持续验证。

## 非目标

当前版本不做实盘交易、券商接口、分钟线高频、多人权限和真实资金管理。若进入生产级协作，需要继续补充托管数据库、身份认证、权限控制、审计日志和任务队列。
