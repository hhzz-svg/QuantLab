# 06 产品介绍素材

## 企业级定位

QuantLab 是面向企业内部投研和策略验证场景的智能量化回测平台。系统已完成公网化部署：Cloudflare Pages 提供前端访问入口，Render Web Service 提供后端 API 服务，自定义域名 `quantlab.aihzcc.top` 与 `api.quantlab.aihzcc.top` 分别承载 Web 应用和 API 能力。

平台把量化研究流程沉淀为“研究对象建立、策略验证、风险评估、参数优化、研究报告”的标准闭环，适合用于项目评审、产品展示、策略原型验证和内部研究工作台建设。

## 可展示模块

1. 生产环境入口：线上前端、Render 后端 API、健康检查和 GitHub 部署源。
2. 产品首页：展示研究对象、策略验证、风险评估和报告输出的闭环价值。
3. 需求分析：数据管理、策略配置、回测分析、参数优化和报告导出。
4. 系统设计：Cloudflare Pages + Render + FastAPI + SQLite + Vue 3 + ECharts 架构。
5. 核心算法：事件驱动回测、风险收益指标、参数网格搜索。
6. 系统实现：数据中心、策略中心、回测引擎、前端可视化。
7. 测试与结果分析：单元测试、接口测试、部署配置测试和示例策略回测结果。
8. 后续规划：托管数据库、认证权限、审计日志、任务队列、多资产组合和机器学习模型。

## 产品亮点表达

- 将量化研究流程从一次性脚本升级为可访问、可复盘、可展示的研究平台。
- 同时提供策略研究、参数优化、历史任务、图表展示和报告输出闭环。
- 线上前端已接入 Render 后端 API，不再停留在单机演示或本地服务阶段。
- 用 SQLite 保存轻量研究数据，便于快速演示；后续可替换为托管数据库支撑企业级协作。
- 以清晰的 API、部署配置和验证命令保证平台具备持续交付基础。

## 一句话介绍

QuantLab 是一个已完成前后端公网部署的智能量化投研平台，用标准化工作流帮助投研人员完成策略验证、风险复盘、参数实验和研究报告沉淀。
