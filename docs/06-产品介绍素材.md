# 06 产品介绍素材

## 可展示模块

1. 产品首页：展示研究对象、策略验证、风险评估和报告输出的闭环价值。
2. 需求分析：数据管理、策略配置、回测分析、参数优化和报告导出。
3. 系统设计：FastAPI + SQLite + Vue3 + ECharts 架构。
4. 核心算法：事件驱动回测、风险收益指标、参数网格搜索。
5. 系统实现：数据中心、策略中心、回测引擎、前端可视化。
6. 测试与结果分析：单元测试、接口测试、示例策略回测结果。
7. 后续规划：接入更多数据源、扩展多资产组合和机器学习模型。

## 产品亮点表达

- 将量化研究流程浓缩为可上手的策略验证产品。
- 同时提供策略研究、参数优化、历史任务、图表和报告闭环。
- 用 SQLite 保存可复现实验，便于复盘、演示和持续迭代。
