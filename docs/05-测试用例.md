# 05 测试用例

测试文件：

- `tests/test_platform_core.py`
- `tests/test_online_market_flow.py`
- `tests/test_product_homepage_copy.py`
- `tests/test_docs_and_optimization_templates.py`
- `tests/test_deployment_config.py`

覆盖内容：

1. 数据清洗：字段映射、日期排序、重复去重、缺失 close 拒绝。
2. 在线行情：`auto` 自动选择 yfinance/AKShare/CSV，并验证 yfinance 空数据和 Eastmoney 断连时的备用行情链；预览接口返回 quote 和 chart。
3. 策略中心：6 类策略均有参数 schema 且能输出信号。
4. 回测引擎：手续费、滑点、订单、成交、权益曲线。
5. 指标分析：收益、波动、回撤、夏普、卡玛、胜率、月度收益。
6. 参数优化：网格数量、排序和最优回测 ID。
7. API：策略列表、CSV 上传、行情查询、创建回测、查询详情、404、报告、优化。
8. 前端回归：扫描 `frontend/src` 全目录，验证首页、策略库和常用研究标的保持产品化表达，禁止旧文案回归。
9. 前端结构：验证前端已拆分为 store / api / format / charts / styles / components / pages 模块，且七个页面组件齐备。
10. 前端呈现约束：结果页必须渲染后端全部 10 项指标与交易明细、订单流水；涨跌配色为红涨绿跌且带正负号；风险提示常驻。
11. 部署配置：`render.yaml` 命令、正式域名口径、前端 API 基址能力、演示兜底显式标记、SFC 构建插件。
12. 文档与优化模板：说明文档使用当前接口口径，6 类策略均有匹配的参数优化网格。

运行：

```powershell
python -m pytest -q
```
